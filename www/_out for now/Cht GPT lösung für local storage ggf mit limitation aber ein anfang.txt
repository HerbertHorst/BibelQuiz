If you want to store the data client-side and still be able to access it offline, you could consider using local storage. Local storage is a client-side storage solution that's part of the web browser and allows you to store key-value pairs of data. The data is stored on the user's device and is available even when the device is offline.

Keep in mind that local storage has some limitations, such as a limited amount of storage space (usually around 5 MB) and the fact that it's tied to a specific browser and device. Additionally, data stored in local storage is accessible to any scripts on the same domain, so you'll need to make sure to properly secure any sensitive data.
